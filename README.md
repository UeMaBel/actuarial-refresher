# Actuarial Refresher

A linked Obsidian vault for revisiting actuarial mathematics, insurance, financial modelling, and solvency reporting. 

## Start here

Open this folder as a vault in [Obsidian](https://obsidian.md/), then begin with **Actuarial Refresher.md**. 

## Vault contents

- **Guided route:** [[Actuarial Refresher]]
- **Foundations:** probability, statistics, survival models, and mathematics
- **Insurance:** life, health, and motor products, pricing, and reserving
- **Financial modelling:** stochastic processes, scenario generation, and valuation models
- **Risk and reporting:** Solvency II, ORSA, IFRS, and risk measures

## Using the notes

The notes use Obsidian wikilinks such as `[[Probability]]`. Obsidian resolves these links when the folder is opened as a vault. The `.obsidian` directory contains shared vault settings; personal workspace state, plugin installs, and caches are excluded by `.gitignore`.

This is a study refresher, not a complete professional syllabus or a substitute for current regulatory and accounting guidance. External references are included in relevant notes for further reading.
